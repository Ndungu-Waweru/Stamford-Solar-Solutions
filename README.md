# Stamford Solar Solutions

A Next.js storefront and lead generation site for a solar energy business.

## Features

- Public storefront and product catalog
- Project showcase and solution pages
- Quote request flow
- Admin dashboard scaffolding
- API routes for products, orders, quote submissions, and admin login

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open http://localhost:3000

## Project structure

The app follows a modular layout with public pages, reusable components, and data-driven content.
